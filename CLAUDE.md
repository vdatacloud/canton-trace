# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Project

**canton-trace** (`github.com/vdatacloud/canton-trace`, Apache-2.0, public) reads a Canton / Daml ledger
transaction as a **tree**, as the reading party may see it. It is a general-purpose library for any Canton
application: nothing here may depend on, name or assume a particular application's templates, parties or
domain. `README.md` is the user-facing reference; keep it current with every API change.

## Commands

- `make verify`: the local gate (build, vet, unit tests). Run before pushing; the pre-push hook runs it.
- `make test`: unit tests. They need no network, Docker or ledger; keep it that way.
- `make lint`: golangci-lint with the default config, as CI runs it.
- `make vuln-check`: govulncheck (needs network). CI runs it on every PR and weekly.
- `make install-hooks`: installs the pre-push hook.
- Releases: merging to `main` auto-tags semver from the Conventional Commits since the last tag (`RELEASING.md`,
  `scripts/next-version.sh`). `feat:` gives a minor, `fix:`/`perf:`/`refactor:`/`build:` a patch,
  docs/test/ci/chore nothing. Stay `v0.x`.

## Layout

- `trace.go`: the `Trace` and `Node` types (the JSON shape consumers depend on: change it only additively).
- `build.go`: `Build` rebuilds the tree from pre-order node ids and `LastDescendantNodeID` with one stack pass.
- `grpc.go` (`FromTransaction`, `GRPCReader`, `Simulator`), `jsonapi.go` (`ParseJSONTransaction`, `JSONReader`):
  the two transports. `FromPrepared` adapts an interactive-submission prepared transaction.
- `value.go`: Daml values in the JSON Ledger API encoding, on both transports.
- `explain.go`: `Explain` reads a ledger error (ErrorInfo, RequestInfo, RetryInfo, a JSON error body).
- `render.go`: the text tree. `traceapi/`: HTTP handlers. `cmd/canton-trace/`: the CLI.

## Rules

- **Never widen a read.** The reading parties always come from the caller; the ledger enforces the projection. A
  visible node whose parent is hidden attaches to its nearest visible ancestor, or becomes a root. No visible
  event is lost, and the tree is never deeper than the ledger's.
- **Transport equivalence.** A transaction read over gRPC equals the same transaction read over JSON (values in the
  JSON API encoding; an absent argument or result is left out on both). Every adapter change keeps the
  equivalence tests passing, and a new field lands on both transports in the same change.
- **Simulation never submits.** `Simulator` calls `PrepareSubmission` only; nothing is signed or executed.
- **Secrets stay out.** A bearer token comes from the caller (`WithBearer`) or the CLI's `CANTON_TOKEN`, never a
  flag, a log line or an error message.
- **Public repo: synthetic data only.** Test fixtures, examples and images use made-up or LocalNet development
  parties and ids, never data from a real deployment.
- **Errors** wrap with context (`fmt.Errorf("reading update %s: %w", id, err)`). No `panic` in library code.
- **Dependencies** stay few and current (gRPC, the Ledger API protos); `govulncheck` must pass.

## Git

Conventional commit prefixes, commits signed off (`-s`). Changes land through a PR, never a direct push to
`main`. Policy in `.gemini/repo_rules.md`; git and CI mechanics in `.agents/skills/github-ci/SKILL.md`.
`graphify-out/` is regenerated by CI on `main` after merge, never locally, and a PR must not touch it.
